# Güvenlik bildirimi / Security reporting

Desteklenen sürüm / Supported version: **0.1.x development previews**.

Güvenlik açığını herkese açık issue'ya kişisel veri veya çalışan saldırı
ayrıntıları ekleyerek bildirmeyin. GitHub'ın **Security → Report a vulnerability**
kanalını kullanın: https://github.com/sendagburak/umumay/security/advisories/new

Please use GitHub's private vulnerability reporting channel above. Include
the affected version, a minimal reproduction using synthetic data, the
expected boundary and observed impact. Do not attach personal URLs,
package inventories, system reports or credentials.

Normal hatalar için Issues kullanılabilir. Gizlilik ve yetki sınırları:
[güvenlik tasarımı](docs/SECURITY.md). Private reporting düğmesi görünmüyorsa
hassas ayrıntıları herkese açık yayımlamayın.

The source audit of 0.1.2 found no validated reportable vulnerability within
its documented scope. It is not a full audit of 0.1.3 or its native dependencies,
and it does not guarantee that the application is free of vulnerabilities.
